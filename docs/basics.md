# 基本玩法

> 本页依据《影之诗：进化对决》官方综合规则整理。关键词的中文译名以简中官方《规则》说明为准（例如 Bane 是【毁灭】而不是「必杀」，Drain 是【虹吸】而不是「吸血」）。

## 游戏是什么

《影之诗：进化对决》（Shadowverse: Evolve）是 Cygames 与 Bushiroad 合作推出的实体集换式卡牌游戏，以手游《影之诗》为蓝本。但它**不是手游规则的实体化**——进化牌组、横置攻击、【快速】响应这些机制只存在于实卡版本。

每局对战由两名玩家进行，各自用一张**主战者**卡代表自己，并按主战者的**职业**（或某个**主题**）构筑牌组。轮到自己时，出随从、放护符、用法术、让随从攻击或进化；把对方主战者的生命值打到 0 即可获胜。

| 项目 | 说明 |
|---|---|
| 人数 | 2 人（1 对 1） |
| 单局时长 | 通常 15–30 分钟 |
| 上手难度 | 低。会读卡面就能开局，真正的门槛是「横置」和「进化牌组」 |
| 需要准备 | 两副牌组、指示物、进化点卡、骰子或猜拳 |

## 获胜目标

满足下面任意一条即获胜：

1. **对手主战者的生命值降到 0 或以下**；
2. **对手的牌组为 0 张，却需要抽牌**。

如果双方同时满足胜负条件，本局为**平局**。

有两点容易记错：

- 主战者的生命值**没有上限**，回复可以超过初始的 20 点；
- 「牌组抽空」只在**需要抽牌时**才判负——牌组刚好剩 0 张并不算输。

## 开始前的准备

### 牌组构筑

| 项目 | 规则 |
|---|---|
| 主牌组 | **40–50 张**，由随从、法术、护符组成 |
| 进化牌组 | **最多 10 张**，只能放进化随从（以及部分高阶卡） |
| 同名卡上限 | 主牌组、进化牌组**各自**最多 3 张 |
| 可用卡牌 | 主战者职业的卡 + 中立卡；或该主战者所属「主题」的卡 |
| 主战者 | 1 张，开局时背面朝上放到主战者区 |

职业共 6 种：精灵、皇家护卫、巫师、龙族、梦魇、主教。

### 开局步骤

1. 双方把主战者卡**背面朝上**放到主战者区，确认后同时翻开；
2. 能量点最大值与剩余能量点都设为 **0**，主战者生命值设为 **20**；
3. 猜拳或掷骰决定先后手，**后手玩家获得 3 张进化点卡**（先手没有）；
4. 洗牌，双方各抽 **4 张**作为起手；
5. 决定是否换牌：只能**全部保留**或**全部更换**——换牌时把手牌以任意顺序放回牌组底部，再抽 4 张，每人只能换一次，由先手先决定；
6. 双方喊出「对决！影之诗！」，先手开始第 1 回合。

### 需要准备的道具

- **指示物**：记录随从受到的伤害与攻防修正（数值指示物）、主战者的生命值（体力指示物）；
- **进化点卡**：后手 3 张，进化时代替能量点使用；
- **卡垫**：标出各区域位置。没有也能玩，但会明显更慢。

官方把卡面拆成十三项，其中真正影响对局的是这几项：

| 编号 | 名称 | 怎么用 |
|---|---|---|
| ⑤ | 费用 | 使用时要支付的能量点 |
| ⑦ | 攻击力 | 攻击时对敌方造成的伤害 |
| ⑧ | 生命值 | 减到 0 或以下即破坏 |
| ⑥ | 效果文本 | 入场曲、启动能力、关键词等 |
| ③ | 种类 | 随从 / 进化随从 / 法术 / 护符 / 主战者 |
| ④ | 类型 | 种族或系列（如「绝杰」「士兵」），部分卡的效果会参照 |
| ② | 职业 | 用卡框颜色表示，构筑时以此为准 |
| ① | 卡牌名称 | 判断「同名卡最多 3 张」的依据 |
| ⑫ | 稀有度 | 只影响收藏价值，不影响规则 |

剩下的 ⑨ 衍生物信息、⑩ 卡图、⑪ 背景文本、⑬ 附注 属于信息性内容，不影响对战。

卡牌分六种：

| 种类 | 说明 |
|---|---|
| 随从 | 战斗主力。出场当回合不能攻击，除非有【疾驰】或【突进】 |
| 进化随从 | 放在进化牌组里，用来盖在场上同名随从上面完成进化 |
| 法术 | 使用后立即结算，然后进入墓场 |
| 护符 | 留在战场上持续提供能力，部分需要支付费用或进入墓场才发动 |
| 主战者 | 你的化身，生命值归零即败北 |
| 衍生物 | 由能力生成、不属于牌组的卡；进入战场与额外区以外的区域时从游戏中移除 |

## 回合流程

<figure>
  <img src="/images/basics/turn-flow.png" alt="回合的三个阶段">
  <figcaption>图 3：官方「回合进行表」——同一个场面在三个阶段里的样子</figcaption>
</figure>

### 开始阶段

- 能量点最大值 +1（上限 10），剩余能量点补满；
- 所有横置的卡转回竖置；
- 从牌组抽 1 张（**先手第 1 回合不抽**）。

### 主要阶段

先处理「主要阶段开始时」的能力，然后可以**任意顺序、任意次数**进行：

- 使用卡牌（支付费用）；
- 使用启动能力；
- 随从进行攻击；
- 进化随从（**每回合只能 1 次**）。

### 结束阶段

- 处理「结束阶段开始时」的能力；
- 可以把自己持有【守护】的随从横置；
- 对手可以在这个时点使用【快速】卡牌；
- 手牌 8 张以上时，弃到 7 张。

## 三个关键机制

### 横置与竖置：决定谁能被打

随从攻击时要**横置**（把卡横过来），表示它这回合已经行动过。而规则规定：**你只能攻击对手横置状态的随从，或者直接攻击主战者**——竖着的随从是打不到的。

这相当于给所有随从半个「潜伏」：不想被交换掉的效果随从，可以一直竖着；反过来，你想解掉对方的随从，往往得先逼它动起来，或者用【指定攻击】、法术与能力。

<figure>
  <img src="/images/basics/attack.png" alt="攻击目标规则">
  <figcaption>图 4：能攻击的目标只有主战者和横置（已行动）的随从</figcaption>
</figure>

横置的卡会在**自己回合开始时**全部竖回来。把卡横过来还是竖着，是新手最容易摆错的地方之一：<Term label="横置">把卡横过来，表示这回合已经行动或已支付费用。攻击、部分启动能力和【守护】都会让卡横置。</Term> 一旦摆反，对手和你自己都会误判能不能攻击。

### 进化：从进化牌组叠上去

进化不是随从自带的：能进化的随从，**必须在进化牌组里有对应的进化卡**。支付进化费用后，从进化牌组取出同名进化卡，盖在场上那张随从上面。

</figure>

要点：

- 进化费用用能量点支付，每 1 点费用可以用 1 张<Term label="进化点">后手玩家在开局获得的 3 张卡。进化时代替 1 点能量点使用，每次进化最多用 1 张；先手玩家没有进化点。</Term>代替，每次进化最多用 1 张；
- 因为只有后手有进化点，实际效果是「后手能更早、更便宜地进化」；
- 每回合只能进化 1 次，但**不限回合数**——付得起费，第 1 回合就能进化；
- 进化后换用进化卡的数值与能力，**身上的伤害与状态指示物保留**；
- 进化随从离场时，进化卡正面朝上放回进化牌组顶部（视为已从游戏中移除），未进化的那张进墓场。

还有一个容易忽略的细节：**当回合出场、当回合进化的随从，可以攻击对手横置的随从**（但仍不能攻击主战者）。

### 快速：对手回合唯一的响应窗口

带【快速】的卡可以在**对手回合**的两个时点使用：

1. 对手的随从攻击时；
2. 对手的结束阶段。

这是实卡版相对手游版最大的改动——你不再只能干看着对手操作。带<Term label="快速">带【快速】标记的卡牌，可以在对手回合的「随从攻击时」或「结束阶段」使用。</Term>的卡常见用途是补刀、保护随从或临时加身材。

## 和手游版的区别

| 差异点 | 实体卡 | 手游 |
|---|---|---|
| 职业 | 6 种（死灵与吸血鬼合并为「梦魇」，没有复仇者） | 8 种 |
| 先手第 1 回合 | **不抽牌** | 抽 1 张 |
| 进化 | 需要**进化牌组**里对应的进化卡 | 随从自带进化 |
| 进化点 | 只有**后手** 3 张 | 双方都有 |
| 攻击随从 | 只能打**横置**的随从 | 没有横置概念 |
| 对手回合 | 可以用【快速】响应 | 不能操作 |
| 生命值 | 20 点，**无上限** | 20 点，有上限 |
| 起手换牌 | 全留或全换，只能换一次 | 可逐张换 |

## 第一局演示

以下是示意，用来说明回合推进的节奏（不代表具体卡表）：

- **起手**：2 张 1 费随从、1 张 2 费法术、1 张 3 费随从。你先手，不换牌。
- **第 1 回合**：能量点 1，出一张 1 费随从。它出场当回合不能攻击，结束回合。
  （先手第 1 回合不抽牌。）
- **对手第 1 回合**：能量点 1，同样只能出一张低费随从，结束。
- **第 2 回合**：能量点 2，抽 1 张。你可以再出一张 1 费随从，或留着费用用【快速】。
  这一回合你的随从可以攻击了——但对手的两个随从都竖着，**你只能打主战者**。攻击后你的随从横置。
- **对手第 2 回合**：对手可以攻击你**横置**的那个随从，把它换掉；或者打你的主战者。
- **第 3 回合**：能量点 3，抽 1 张。这里通常要做选择：铺场、解掉对手的威胁，还是进化一个随从抢节奏。

到这一阶段你应该已经体会到：**横置的时机**决定了对手能不能解掉你的随从，而**进化**是你唯一能主动「变强」的动作。

## 常见错误

- 以为竖着的随从也能被打——**只有横置的随从**才是合法目标；
- 先手第 1 回合照样抽牌（**不抽**）；
- 进化时直接从手牌或牌组里找卡（必须从**进化牌组**取同名进化卡）；
- 把 3 张进化点一次性用在一次进化上（**每次进化最多 1 张**）；
- 攻击后忘了把随从横置，导致对手误判；
- 结束阶段忘了把 8 张手牌弃到 7 张；
- 以为主战者生命值最多 20 点（可以超过）。
