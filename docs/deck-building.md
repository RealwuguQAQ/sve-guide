# 怎么组卡

## 确认赛制
<div class="template-note">填写主要赛制及各自允许使用的卡池。</div>

## 构筑限制
<div class="template-note">填写卡组张数、同名卡上限、职业、颜色和额外卡组限制。</div>

## 确定获胜思路
<div class="template-note">填写卡组如何获胜、核心卡是什么、需要哪些配合。</div>

## 卡牌比例与费用曲线
<div class="template-note">解释资源、低费、中费、高费、解牌和抽牌的比例。</div>

## 从模板牌表开始
<div class="template-note">放一套入门牌表，标出必需卡、替换卡和升级顺序。</div>

## 测试与调整
<div class="template-note">填写如何记录卡手、资源不足、关键卡上手率与对局表现。</div>

## 提交前检查
- [ ] 张数符合规则
- [ ] 同名卡没有超限
- [ ] 所有卡属于当前赛制
- [ ] 准备了需要的指示物和衍生物
- [ ] 已经实际洗牌并测试起手
