# 名词解释

## 悬浮解释怎么写

在任何 Markdown 页面中使用：

```html
<Term label="关键词">这里填写简短、准确的解释。</Term>
```

显示效果：正文中的 <Term label="关键词">这里填写简短、准确的解释。鼠标悬停、键盘聚焦或手机点按即可查看。</Term> 会带有虚线下划线。

## 规则关键词

> 中文名以简中官方《规则》说明为准。部分译名和手游版不同，注意别混。

| 关键词 | 英文 | 效果 |
|---|---|---|
| 【入场曲】 | Fanfare | 卡牌进入战场时发动 |
| 【谢幕曲】 | Last Words | 从战场进入墓场时发动 |
| 【快速】 | Quick | 可以在对手回合的「随从攻击时」或「结束阶段」使用 |
| 【启动】 | Activated | 主要阶段支付费用发动；费用里含「横置」也能在出场当回合使用 |
| 【能力名】 | Named ability | 一次性或带条件的特殊能力，按卡面文字发动 |
| 【威压】 | Intimidate | 不能被对手的随从攻击，但**可以被能力指定** |
| 【灵气】 | Aura | 不能被对手的能力指定，但**可以被攻击** |
| 【指定攻击】 | Assail | 可以攻击对手**竖置**的随从；打不到持有【威压】的随从 |
| 【守护】 | Ward | 对手攻击时，若有横置的守护随从则必须打它；可在入场时或自己结束阶段主动横置 |
| 【疾驰】 | Storm | 入场当回合就能攻击主战者或横置的随从 |
| 【突进】 | Rush | 入场当回合就能攻击横置的随从 |
| 【毁灭】 | Bane | 与它交战的随从在战斗伤害之后被破坏（不需要真的造成伤害） |
| 【虹吸】 | Drain | 攻击造成伤害时，自己主战者回复等量生命；被攻击时不发动 |
| 【连击_n】 | Combo (X) | 本回合已使用 n 张卡以上时发动（自身也计入） |
| 【魔力连锁_n】 | Spellchain (X) | 自己墓场中的法术 ≥ n 张时发动（自身不计入） |
| 【土之秘术】 | Earth Rite | 移除自己战场上 1 个蓄积指示物发动；可以不发动 |
| 【蓄积】 | Stack | 带 1 个蓄积指示物入场；离场时改为减 1 个指示物，减到 0 破坏；可把指示物转给另一个蓄积护符 |
| 【觉醒】 | Overflow | 能量点最大值 ≥ 7 时发动 |
| 【唤灵充能_n】 | Necrocharge (X) | 自己墓场中的卡 ≥ n 张时发动（自身不计入） |
| 【真红】 | Sanguine | 本回合自己主战者的生命值减少过即成立（之后回血也算） |

### 容易混的三组

**【指定攻击】/【威压】/【灵气】**：三个都在管「能不能被选中」，但方向不同。

- 【威压】：防**攻击**，不防能力；
- 【灵气】：防**能力**，不防攻击；
- 【指定攻击】：专门破「竖置」，但被【威压】挡住。

**【蓄积】/【土之秘术】**：蓄积是「指示物本身」，土之秘术是「花掉指示物换效果」。没有蓄积指示物时，土之秘术就发动不了。

**【连击】/【魔力连锁】/【唤灵充能】**：都是「数够了才发动」，但数的是三样东西——本回合使用的卡数、墓场里的**法术**数、墓场里的**所有卡**数。

### 通用术语

| 术语 | 含义 |
|---|---|
| 能量点（PP） | 使用卡牌与发动能力的资源，每回合 +1，上限 10 |
| 进化点（EP） | 后手开局的 3 张卡，进化时代替 1 点能量点 |
| 主战者 | 代表玩家的卡，生命值归零即败北 |
| 牌组 | 主牌组（40–50 张） |
| 进化牌组 | 进化随从组成的牌组（≤10 张） |
| 战场 | 随从与护符所在的区域，最多 5 张 |
| 额外区 | 相当于第二手牌，最多 5 张，可以直接使用 |
| 墓场 | 被破坏的随从与护符、用过的法术、弃掉的卡 |
| 消失 | 被「消失」处理的卡所在区域，相当于除外 |
| 破坏 | 随从生命值降到 0 或以下，或效果直接使其离场 |
| 横置 / 竖置 | 卡牌的两种朝向；横置表示已行动或已付费，竖置表示还能行动 |
| 衍生物 | 由能力生成、不属于牌组的卡 |
| 职业 | 主战者所属的六个职业之一 |
| 主题 | 跨职业的构筑系列，可按主题组牌 |

## 玩家常用语

### 起手

开局抽到的 4 张牌。也指「开局手牌够不够打」，例如「这局起手很顺」。

### 卡手

手里全是高费牌或对不上场面，前期什么都做不了。这个说法在各类 TCG 里通用。

### 铺场 / 解场

铺场是把随从铺到战场上；解场是把对手的随从或护符清掉。

### 换牌

开局那次「全部换掉重抽 4 张」的动作。实体卡只能全换或全留，不能挑着换。

### 斩杀

算出这回合能把对手主战者打到 0 的组合，然后一波带走。

### 快攻 / 中速 / 控制

三种常见牌组思路：抢血、按费用曲线滚雪球、拖到后期用高质量卡取胜。**属于玩家分类，不是官方术语。**

## 收卡与交易用语

### 卡况

卡的品相。常见描述如「全新未开封」「仅拆检」「边角有白边」。交易前最好要**实拍图**。

### 裸卡 / 卡砖 / 卡套

裸卡是没有额外保护的卡；卡砖是硬质保护壳；卡套是软质保护套。邮寄裸卡容易在路上压坏。

### 闪卡（FOIL）

表面有反光压纹的版本，通常比平卡贵。

### 异画

同一张卡的不同插画版本，通常是稀缺版本，价格差异很大。

### 单收 / 整盒 / 拆卡

单收是按张买指定卡；整盒是买一整个补充包盒子；拆卡是把盒子拆开卖单卡。

> 交易价格随环境波动，以当日实际成交为准；这里只解释词义，不提供报价。

## 赛事用语

### 构筑赛

赛前提交固定牌表、现场用自己牌组比的赛制，是店赛和积分赛最常见的形式。

### 现开赛

现场拆包、用拆到的卡组牌比赛。**是否举办以官方赛事公告为准。**

### 瑞士轮

所有选手都打固定轮数，按积分配对，不淘汰，最后按成绩排名。

### 单败淘汰

输一场即出局，常见于八强之后的阶段。

### BO3 / BO1

三局两胜 / 一局定胜负。

### 店赛

在认证牌店举办的日常赛事，通常奖励是卡包或周边。

> 具体赛制、轮数与判罚以官方《泛用赛场规则》和当场裁判说明为准。
