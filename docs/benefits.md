# 实体卡福利

## 大学生积分奖励-YAOPOPS校园行

大学生在微信小程序搜索「**YAOPOP校园**」注册账号，参加积分赛后可以获得一定积分，用来兑换卡盒、盒子等奖品。

### 高校积分获取规则

- **校内活动**：合作高校通过合规、真实的线下《影之诗：进化对决》校园活动，经过校园大使现场核销即可积累积分。
- **校外赛事**：目前仅限于日常店铺赛事与高校专属赛事。
- **发放机制**：
  1. 积分非实时到账。每周官方统一拉取线下核销数据进行审核匹配，匹配成功后积分发放至你的 YAOPOP 校园行小程序账户；
  2. 积分仅在注册 YAOPOP 账号后开始计算。
- **账号绑定与匹配**：务必保证小程序中绑定的影之诗 ID，与线下参与活动使用的《口袋影之诗》ID 完全一致。
